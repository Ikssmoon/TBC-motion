# TBC guide animations

All in-app guide animations (Home, PFM, Accounts) in light and dark, as MP4 and Lottie.

Open `index.html` to preview and download single files or whole guides as a zip.

## Folders

- `home/` - Home guide: Edit quick actions, Search, Notifications, Concept centre (EN / KA)
- `pfm/` - PFM guide: Set starting date, Date range, Three different charts, Expenses / Income (EN / KA)
- `accounts/` - Accounts guide: auto-hide and drag to hide, list and carousel widget

Each has `mp4/` and `lottie/` subfolders. File names end in `-dark` / `_dark` for dark mode and `-ka` / `_ka` for Georgian.
