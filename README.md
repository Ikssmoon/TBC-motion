# TBC guide animations

All in-app guide animations (Home, PFM, Accounts) in the Mass, Concept and Wealth styles, light and dark, as MP4 and Lottie.

Open `index.html` to preview and download single files or whole guides as a zip.

## Folders

- `home/` - Home guide: Edit quick actions, Search, Notifications, Concept centre, Burger menu (Concept and Wealth only, light only) (EN / KA)
- `pfm/` - PFM guide: Set starting date, Date range, Three different charts, Expenses / Income (EN / KA)
- `accounts/` - Accounts guide: empty accounts hidden and drag to hide, list widget

Each has `mp4/` and `lottie/` subfolders. File names end in the style (`mass`, `concept`, `wealth`), with `-dark` / `_dark` for dark mode and `-ka` / `_ka` for Georgian.
